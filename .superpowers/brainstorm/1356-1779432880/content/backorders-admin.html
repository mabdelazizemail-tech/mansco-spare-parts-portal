B — Grouped by Order Cards

Backorder items grouped under their parent order as expandable cards. Each card header shows the order number, type, and badge counts (confirmed vs backordered). Items within show part info, current ETA, and slippage. More contextual — the dealer sees backorders in the context of the full order. Less dense than a flat table.

Admin Fulfillment Dashboard

The admin view for monitoring fulfillment across all dealers

A

Metrics + Action Queues

Top row: KPI cards (total shipments in transit, invoices overdue, backorders at risk, avg fulfillment time). Below: three tabbed queues — "At-Risk Backorders" (ETA slipped past threshold), "Overdue Invoices" (past due, sorted by aging), "Pending Shipments" (ready to dispatch). Each queue is actionable — admin can click to update ETA, send reminders, or update status. Plus a "View as Dealer" button for impersonation.

B

Three-Column Dashboard

Three equal columns side by side: Shipments (active, by carrier, status breakdown), Invoices (aging chart, overdue list), Backorders (at-risk list, ETA slippage heatmap). Each column is a self-contained mini-dashboard. Dealer search bar at the top for impersonation. Good for monitoring at a glance, but less focused on action.

C

Alerts-First Feed

A prioritized feed of fulfillment events and alerts. Top: critical alerts (backorders past threshold, large overdue invoices, failed deliveries). Middle: recent activity feed (new shipments, ETA changes, payments received). Bottom: summary charts. Think of it as a fulfillment "inbox" — the most urgent items float to the top. Impersonation via dealer search. Best for admins who need to react to issues rather than browse data.

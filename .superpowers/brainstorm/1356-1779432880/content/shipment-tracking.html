Shipments List Page

Should shipments have their own dedicated page, or live only within orders?

A

Embedded in Orders Only

Shipment tracking appears inside the order detail page (as a section). No separate /dashboard/shipments page. Dealers find tracking by going to their order. Simpler navigation, fewer pages.

B

Dedicated Shipments Page + Order Embed

Add a /dashboard/shipments page listing all active shipments across orders (filterable by status, carrier). Clicking opens the tracking detail. The order detail page also shows a compact shipment summary. Best for dealers with multiple active shipments.

C

Unified Fulfillment Page

A single /dashboard/fulfillment page with tabs: Shipments | Invoices | Back-Orders. All fulfillment tracking in one place. Reduces sidebar links but groups related concepts. The sidebar "Invoices" and "Back Orders" links merge into "Fulfillment".
